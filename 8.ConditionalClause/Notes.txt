🔹 1️⃣ What is a Conditional Statement?
A conditional statement is used to run code based on a condition.

Simple meaning:
If a condition is true → run some code
If it is false → run something else
JavaScript checks the condition using Boolean logic.

🔹 2️⃣ if Statement (Core Concept)
Basic syntax:
if(condition){
   // code runs if true
}

🧠 Important Understanding
The condition inside if is always converted like this:
Boolean(condition)
So:
if("Hello")
is actually:
if(Boolean("Hello")) // true

Example:
let age = 20;
if(age >= 18){
   console.log("Eligible to vote");
}

🔹 3️⃣ if...else Statement
Used when we want two outcomes
if(condition){
   // true block
}else{
   // false block
}


Example:
let age = 16;
if(age >= 18){
   console.log("Adult");
}else{
   console.log("Minor");
}

🔹 4️⃣ else if (Multiple Conditions)
When we have multiple cases
if(condition1){
   // code
}else if(condition2){
   // code
}else{
   // default
}

Example:
let marks = 85;
if(marks >= 90){
   console.log("A Grade");
}else if(marks >= 70){
   console.log("B Grade");
}else{
   console.log("Needs Improvement");
}

🔥 Important Point
JavaScript checks top to bottom.
Once a condition becomes true → it stops checking further.

🔹 5️⃣ Common Beginner Mistake
if(age = 18) ❌ (assignment)
Correct:
if(age === 18) ✔ (comparison)
